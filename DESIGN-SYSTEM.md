# Design System

> This visual design system is a living document and should be updated as visual decisions are approved during the staged build process.

## Design direction

Quiet Luxury × Editorial × Cinematic Interaction

The website should feel like a premium contemporary architecture/interior-design studio rather than a generic business website.

Primary reference influences:

- Bellonii Design Studio — warmth, sophistication, studio credibility, refined presentation
- Azimetri — restraint, whitespace, intentional typography, architectural calm
- Elyra Interiors — cinematic storytelling, atmospheric presentation, sophisticated scrolling behavior
- Arch Decode — professional project presentation, services/process structure, trust and credibility

These references are inspiration only. Do not copy layouts, text, branding, assets, or distinctive design elements.

## Overall feel

- Premium
- Architectural
- Sophisticated
- Warm but restrained
- Editorial
- Contemporary
- Human-designed
- Confident without being loud

Avoid:

- Generic AI-template appearance
- Excessive cards
- Excessive gradients
- Excessive glassmorphism
- Overly rounded UI
- Huge numbers/metrics used as decoration
- Gimmicky animations
- Excessive cursor effects
- Generic stock-business copy
- CTA-heavy layouts
- Visually noisy interfaces

## Typography

Typography should create a strong editorial hierarchy.

### Hero typography

- Very large
- High visual impact
- Short statements
- Strong contrast between headline and supporting copy
- Architectural/editorial rather than SaaS

### Body typography

- Clean
- Highly readable
- Restrained
- Comfortable line height
- Limited type system rather than many different fonts

## Layout

Use generous whitespace and strong visual composition.

The homepage should feel like an editorial architectural publication:

- Large imagery
- Asymmetric compositions where appropriate
- Full-width moments
- Carefully controlled grids
- Strong vertical rhythm
- Sections should not all look structurally identical

The portfolio/project imagery is a primary part of the design, not decoration.

## Hero

The hero should make an immediate visual impact.

Direction:

- Large architectural/interior image
- Very large editorial headline
- Minimal supporting text
- Strong composition
- Clear but understated navigation

The hero may use subtle cursor-responsive movement/parallax.
Interaction must remain sophisticated and restrained.

## Interaction

Use interaction as enhancement rather than decoration.

Potential interactions:

- Subtle cursor-responsive image movement
- Gentle image parallax
- Image depth/movement
- Smooth section transitions
- Project image hover behavior
- Carefully controlled reveal animations

Do not animate everything.
Respect `prefers-reduced-motion`.

## Navigation

The navigation should initially feel clean and integrated with the page.

On scroll, the navigation may transition into a floating translucent navigation surface inspired by modern Apple-style spatial UI.

Characteristics:

- Subtle transparency
- Background blur
- Thin border
- Soft shadow only when necessary
- Compact floating shape
- Smooth transition
- High readability

Do not turn the entire website into glassmorphism.
The glass treatment should primarily be used for the transformed/scrolled navigation.

## Color direction

Use a restrained architectural palette.

Favor:

- Warm whites
- Soft off-whites
- Charcoal
- Deep near-black
- Warm gray
- Muted natural tones

Accent colors should be extremely limited and purposeful.
Do not use loud gradients.

## Photography

Photography is one of the most important visual elements.

Prefer:

- High-quality architectural photography
- Natural light
- Material detail
- Strong compositions
- Atmospheric interiors
- Human-scale spaces
- Texture and craftsmanship

Images should have enough visual presence to carry large layouts.

## Homepage rhythm

The homepage should generally follow an editorial storytelling rhythm:

Hero
→ Studio statement
→ Featured project / immersive project moment
→ Additional selected work
→ Studio philosophy/about
→ Services
→ Process/trust
→ Client stories/testimonials
→ Final project/contact CTA
→ Footer

This is a directional rhythm, not a rigid template. Individual sections should have different compositions where appropriate.

## Responsiveness

The design must work beautifully on:

- Desktop
- Tablet
- Mobile

Mobile should not simply be a compressed desktop layout.
Typography, imagery, spacing, and interactions should be intentionally adapted for smaller screens.

## Design principle

The website should communicate:

"Premium design does not need to shout."

The visual system should rely on:

- Typography
- Photography
- Whitespace
- Composition
- Materiality
- Subtle motion
- Precise interaction

rather than decorative UI effects.

## Notes
