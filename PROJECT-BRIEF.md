# Project Brief

## Project purpose

Build a premium, sophisticated, modern, intentional, trustworthy, human-designed website for a professional interior-design studio.

## Business goal

Present the studio and its work clearly, build trust, and support future project inquiries.

## Development philosophy

Develop incrementally in approved visual stages. Avoid generic templates, invented design decisions, and placeholder content.

## Human-in-the-loop workflow

ChatGPT handles planning, design direction, and review. The implementation agent builds the approved stage. Human approval is required after each major visual stage.

## Technical ownership and portability

Source code must remain portable, independently editable outside GitHub Copilot, Git/GitHub compatible, lightweight, and deployable to common free hosting platforms.

## Current development environment

- Windows development PC with 16 GB RAM
- Node.js LTS 24.19.0 and npm 11.17.0
- Git 2.55.0
- React, TypeScript, and Vite foundation
- Local development during implementation
